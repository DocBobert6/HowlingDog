# Screenshots

Device captures for the README's Screenshots section (Pixel 10a).
The README at the repo root references them by these exact paths.

- `boot.png` — the boot screen (howling-dog icon, HOWLINGDOG, PRESS START).
- `library.png` — the select-grid library, all 13 showcase games with cover art.
- `library-carts.png` — the library with the 8 cartridge games (Metal Slug 3 selected).
- `library-cd.png` — the library with the 5 CD games (Neo Turf Masters selected).
- `library-empty.png` — the empty library ("No games yet"), with the icon in the empty state.
- `game-aes.png` — The King of Fighters '98 on AES, with the arc overlay.
- `game-mvs.png` — Metal Slug 3 on MVS, with the cabinet button layout.
- `game-cd.png` — Aero Fighters 2 on Neo Geo CD, with the diamond overlay.
- `game-cdz.png` — The King of Fighters '99 on Neo Geo CDZ, with the diamond overlay.
- `settings.png` — the Settings screen, scrolled to the CRT display section.

No other files belong here. Do not put BIOS files, games, or ROMs
in this directory — screenshots only.
