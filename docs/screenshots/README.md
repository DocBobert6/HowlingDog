# Screenshots

Device captures for the README's Screenshots section. Add the four
files below to this directory (PNG, taken on the Pixel 10a); the
README at the repo root references them by these exact paths.

- `library.png` — the select-grid library, with cover art.
- `settings.png` — the Settings screen.
- `game-aes.png` — a game running on AES, with the arc overlay.
- `game-cd.png` — a CD game running, with the diamond overlay.

No other files belong here. Do not put BIOS files, games, or ROMs
in this directory — screenshots only.
